## Chrome DevTools-ის შემოწმება

1. გახსენი Chrome → F12 → Console; ფუნქციების გამოყენებისას შეამოწმე შეცდომები.
2. `Ctrl+Shift+M` → Responsive → მიუთითე 375px, 768px და 1440px სიგანე.
3. Performance/Lighthouse ჩანართში გააკეთე გაზომვა; შეინახე სქრინშოტები, თუ ლექტორი ითხოვს.
4. შეიტანე რეალური შედეგები პროექტის ანგარიშში. წინასწარ დაწერილი ან გამოგონილი Lighthouse ქულები არ გამოიყენო.
