# სამუშაო გეგმა — AeroStudy

## 1. პროფესიული ამოცანა და მიზანი

შევქმნა სტუდენტის სასწავლო ამოცანების მართვის ადაპტური ვებგვერდი, სადაც შესაძლებელი იქნება დავალებების დამატება, რედაქტირება, შესრულება, ფილტრაცია და შენახვა. საბოლოო პროდუქტი უნდა მუშაობდეს თანამედროვე დესკტოპისა და მობილურის ბრაუზერებში სერვერის გარეშე.

## 3. ტექნოლოგიები, რესურსები და მეთოდები

- HTML5 — სემანტიკური სტრუქტურისთვის;
- CSS3, Flexbox, Grid — ადაპტური დიზაინისთვის;
- JavaScript (ES2020+) — მოქმედებები, DOM, ლოკალური შენახვა;
- VS Code — ფაილების რედაქტირება;
- Chrome DevTools — მობილურის ხედისა და კონსოლის შემოწმება;
- Git და GitHub — ცვლილებების ისტორიის შესანახად;
- Markdown და PowerPoint — ანგარიშგებისა და დემონსტრირებისთვის.

## 4. როლები და პასუხისმგებლობა

პროექტი ინდივიდუალურია. სტუდენტი პასუხისმგებელია დაგეგმვაზე, UI-ის სტრუქტურაზე, HTML/CSS/JS კოდზე, ფუნქციურ ტესტირებაზე, ვერსიების მართვაზე და საბოლოო პრეზენტაციაზე. საჭიროებისას ინსტრუქციის/დოკუმენტაციის გამოყენება დამხმარე რესურსია; საბოლოო შედეგის გასაგებად ახსნა და შეფასებისთვის წარდგენა სტუდენტის პასუხისმგებლობაა.
