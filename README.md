# AeroStudy — პრაქტიკული ვებპროექტი

**ავტორი:** ლუკა მიქაშავიძე  
**პროგრამა:** SkillWill — Front-end პროგრამირება  
**მოდული:** პრაქტიკული პროექტი (06.1.1.9)  
**ტექნოლოგიები:** HTML5, CSS3 (Flexbox / Grid), Vanilla JavaScript, Git

## მიზანი

AeroStudy ეხმარება სტუდენტს სასწავლო დავალებების ორგანიზებაში. პროექტი აერთიანებს დაგეგმვას, სემანტიკურ ვებგვერდს, რესპონსიულ დიზაინს, JavaScript-ით განხორციელებულ ინტერაქტიულ ფუნქციებს, ოპტიმიზაციის მიდგომებსა და დოკუმენტაციას.

## გაშვება

1. ZIP არქივიდან ამოიღე მთლიანი `AeroStudy_Final_Project` საქაღალდე.
2. გახსენი საქაღალდე Visual Studio Code-ში (`File → Open Folder`).
3. გახსენი `index.html` ბრაუზერში, ან გამოიყენე VS Code-ის Live Server გაფართოება.
4. ინტერნეტი ან npm ინსტალაცია **არ არის საჭირო**.

## ფუნქციები

- დავალების დამატება, რედაქტირება, წაშლა და შესრულებულად მონიშვნა;
- სათაური, საგანი, ვადა და შენიშვნა;
- ძებნა, სტატუსის მიხედვით ფილტრაცია და დალაგება;
- დასრულებული დავალებების ერთიანად წაშლა (დადასტურებით);
- ავტომატური რაოდენობები და შესრულების პროცენტი;
- `localStorage`-ით მონაცემების შენარჩუნება გვერდის განახლების შემდეგ;
- მობილურ ეკრანებზე გახსნა/დახურვადი მენიუ;
- რჩევების კარუსელი წინ/უკან ღილაკებით;
- კლავიატურის ფოკუსი, სათანადო `label`-ები, `aria` ატრიბუტები და reduced-motion მხარდაჭერა.

**პირველი გაშვება:** აპლიკაცია აჩვენებს 3 სადემონსტრაციო დავალებას. ისინი შეგიძლია შეცვალო ან წაშალო; შემდგომი გაშვებისას გამოიყენება შენახული მდგომარეობა.

## ტექნიკური გადაწყვეტილებები

- **HTML5:** `header`, `nav`, `main`, `section`, `article`, `footer`, `dialog`.
- **CSS3:** Grid გამოიყენება მთავარ განლაგებებსა და სტატისტიკის ბარათებში; Flexbox — ნავიგაციასა და საკონტროლო ელემენტებში.
- **JavaScript:** DOM API და Event Delegation; დაცული ტექსტური გამოსატანი ელემენტები გამოიყენება `textContent`-ით (მომხმარებლის შეყვანა არ გადადის `innerHTML`-ში).
- **შენახვა:** JSON მონაცემები ინახება `localStorage`-ში. პირადი მონაცემები სერვერზე არ იგზავნება.
- **ოპტიმიზაცია:** არ გამოიყენება მესამე მხარის ბიბლიოთეკები; JS იტვირთება `defer`-ით; SVG მსუბუქია; გამოიყენება ერთი ცენტრალური Event Listener დავალებებისთვის; CSS მოიცავს მცირე ეკრანების მედია-წესებს.

## შეზღუდვები

- `localStorage` ლოკალურია კონკრეტული ბრაუზერისა და დომენისთვის. სხვა მოწყობილობაზე მონაცემები არ გადადის.
- ბრაუზერის შენახვის აკრძალვისას ცვლილებები მიმდინარე სესიაში მოქმედებს, მაგრამ განახლებისას შეიძლება დაიკარგოს.
- რეალური API/სერვერი და მომხმარებლის ავტორიზაცია პროექტის მოცულობაში არ შედის.

## Git და GitHub

ლოკალურად ჩაწერილია თანმიმდევრული commit-ები. პროექტის GitHub-ზე გამოქვეყნება უნდა შეასრულოს სტუდენტმა **თავის ანგარიშზე**:

```bash
git remote -v
git remote add origin https://github.com/YOUR_USERNAME/aerostudy-final-project.git
git branch -M main
git push -u origin main
```

თუ `origin` უკვე არსებობს, გამოიყენე `git remote set-url origin <მისამართი>` ნაცვლად `git remote add` ბრძანებისა. **არ გაუშვა** `git init`, თუ არქივში უკვე არის `.git` საქაღალდე.
